# AI Context

This directory contains persistent AI engineering context.

Files:

- `WORKFLOW.md` — How the AI agent handles requirements, generates implementation prompts, waits for approval, and implements approved work.
- `ENGINEERING_RULES.md` — Coding, safety, database, API, UI, testing, and diff-review rules.
- `PROJECT_CONTEXT.md` — Stable project architecture and verified technical context.
- `DECISIONS.md` — Important architectural and engineering decisions.

`CLAUDE.md` is the project entry point and instructs Claude to read these files.

The actual repository is always the ultimate source of truth.
